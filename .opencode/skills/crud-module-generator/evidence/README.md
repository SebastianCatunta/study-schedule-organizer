# Evidence Folder

Use this folder only for presentation evidence, not source code.

- `screenshots/01-structure.png`: skill tree showing `SKILL.md`, scripts, references, assets, docs, demo, and tests.
- `screenshots/02-success.png`: successful `python demo/run-demo.py` output.
- `screenshots/03-invalid-input.png`: the same output's rejected invalid case, or a separate close-up.
- `screenshots/04-generated-crud.png`: generated backend/frontend tree in a disposable target project.
- `screenshots/05-tests.png`: project validation, formatter, typecheck, unit, and integration test results.
- `runs/`: optional text logs copied from terminal output; use names matching the screenshots.

Do not capture passwords, JWTs, database URLs, or personal paths. Replace them with placeholders before submitting evidence.
